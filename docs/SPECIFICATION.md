# AviUtl2 プラグイン「プレゼント開封」仕様

Delphi Win64 の単体メディアオブジェクト。プロジェクト名は SYNC_GiftOpen、グループ名は SYNC、日本語の配置名は「プレゼント開封」。

## 包装と画像

包装材を厚み、内外面、曲面、折り目、装飾を含む立体ポリゴンで自動生成する。AviUtl2 のカメラ、光源、深度処理に対応する。プレゼントは指定画像のテクスチャ付きポリゴンとして同一空間に置く。画像の縦横比を保ち、閉じた包装の中へ収める。画像未指定でも開封を描画する。画像自体の移動・回転・変形・拡大は演出に含めず、オブジェクトの配置には標準描画の項目を使用する。

| 包装スタイル | 開封動作 |
| --- | --- |
| リボン付きプレゼント箱 | リボンがほどけ、蓋が外れる |
| 包装紙付きプレゼント箱 | 外装紙が裂け、蓋が外れる |
| 手提げ紙袋 | 折り目が開き、袋の口が広がる |
| 宝箱 | 湾曲した蓋が蝶番で開く |
| 四方向展開式の箱 | 上蓋と四方の側面が展開する |
| 破裂式の箱 | 側面と上蓋が破片に分かれる |
| キャンディ包み | ねじり端が離れ、胴の包装がめくれる |
| リボンによる直接包装 | 巻いた幅広の帯が順にほどける |
| 包装紙による直接包装 | 折り目に沿って紙が裂ける |
| 透明フィルム包装 | 立体の折り目を持つフィルム片が開く |
| バスケット包装 | 上部が開いた編みかごが下がり、中身が見える |
| クリスマスの靴下 | 履き口が開き、靴下が外れる |
| カプセルトイ | 上下の半球が分離する |
| くす玉 | 左右の半球が開き、房が広がる |

包装幅、包装高さ、包装奥行きは画像に依存しない共通寸法。色1と色2から本体と装飾の色を決める。既定はリボン付きプレゼント箱、赤い箱、金色のリボン。包装透明度は0～100、0.01刻みで既定0。主に包装本体へ適用し、半透明の状態では開封前から中身が透けて見える。前面、背面、中身の描画順とアルファを考慮する。

「包装X」「包装Y」「包装Z」はオブジェクト内の相対座標で、各 −8192～8192、0.01 刻み、既定 0。「包装拡大率」は同じ原点を基準とする一様拡大で、0～1000％、0.01 刻み、既定 100％。拡大後に相対座標を加え、包装本体・装飾・開封動作に適用する。0％では包装を表示しない。画像と演出には、これらの包装専用設定を適用しない。画像の設定項目名は「画像ファイル」。

## 時間と演出

開封前時間、開封時間、演出時間はすべて秒単位で 0.01 刻み、既定値は 1.00。開封前時間が0なら直ちに開始し、開封時間が0ならその時点で完了する。包装形式によらず指定時間で開封が終了し、同時に演出が始まる。終了後もプレゼント画像を表示する。タイムライン全体やオブジェクトの表示尺に速度を追従させず、ローカルの経過時間から直接状態を求める。

演出はなし、紙吹雪、紙テープ、キラキラ、星、ハート、放射光、光の噴出、煙、シャボン玉、花びら、花火。初期値は紙吹雪。包装と独立して、時間、量、範囲、色を共通項目で設定する。色は自動配色または指定色、乱数は固定値から評価する。

紙テープは投げ出された軌道に沿って伸び、終盤で透けながら消える。放射光は中心から広がり、光の噴出は下から上に広がる。どちらもプレゼント画像の背後に描画する。花火は時間差で弾け、火花が広がってから徐々に消える。

「演出X」「演出Y」「演出Z」はオブジェクト内の相対座標で、各 −8192～8192、0.01 刻み、既定 0。「演出拡大率」は演出全体をオブジェクト原点の周りで一様に拡大し、0～1000％、0.01 刻み、既定 100％。拡大後に相対座標を加える。0％では演出を表示しない。包装と画像の位置・サイズはそれぞれの設定で決まる。

効果音、音声ファイル、音声生成は搭載しない。
